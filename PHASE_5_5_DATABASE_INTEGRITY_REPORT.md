## 2. INVARIANT AUDIT RESULTS

| Check ID | Integrity Invariant Specification | SQL Validation Logic | Violations Detected | Status |
|---|---|---|---|---|
| **INV-01** | **No Duplicate Registrations**<br>A user cannot have multiple registrations for the same event. | `SELECT "userId", "eventId" FROM registrations GROUP BY "userId", "eventId" HAVING count(*) > 1` | **0** | **PASS** |
| **INV-02** | **No Duplicate Attendances**<br>A single registration cannot have more than one attendance record. | `SELECT "registrationId" FROM attendances GROUP BY "registrationId" HAVING count(*) > 1` | **0** | **PASS** |
| **INV-03** | **No Capacity Overselling**<br>`currentRegistered` must never exceed `maxCapacity` on any event. | `SELECT id FROM events WHERE "currentRegistered" > "maxCapacity"` | **0** | **PASS** |
| **INV-04** | **No Negative Capacities**<br>`currentRegistered` must never drop below 0. | `SELECT id FROM events WHERE "currentRegistered" < 0` | **0** | **PASS** |
| **INV-05** | **Unique Ticket Codes**<br>Every ticket code must be globally unique across all registrations. | `SELECT "ticketCode" FROM registrations GROUP BY "ticketCode" HAVING count(*) > 1` | **0** | **PASS** |
| **INV-06** | **No Orphaned Attendances**<br>Every attendance record must link to an existing registration. | `SELECT a.id FROM attendances a LEFT JOIN registrations r ON a."registrationId" = r.id WHERE a."registrationId" IS NOT NULL AND r.id IS NULL` | **0** | **PASS** |
| **INV-07** | **No Orphaned Waitlists**<br>Every waitlist entry must reference a valid event. | `SELECT w.id FROM waitlists w LEFT JOIN events e ON w."eventId" = e.id WHERE e.id IS NULL` | **0** | **PASS** |
| **INV-08** | **No Orphaned Reminders**<br>Every event reminder record must reference a valid event. | `SELECT er.id FROM event_reminders er LEFT JOIN events e ON er."eventId" = e.id WHERE e.id IS NULL` | **0** | **PASS** |
| **INV-09** | **Unique Waitlist Positions**<br>No two pending entries for the same event may have the same queue position. | `SELECT "eventId", position FROM waitlists WHERE status = 'PENDING' GROUP BY "eventId", position HAVING count(*) > 1` | **0** | **PASS** |

## 4. RELATIONAL CONSTRAINT VERIFICATION

PostgreSQL schema constraint enforcement was confirmed:
- **Foreign Key Cascades**: Tested deleting events cascading to registrations, favorites, notifications, and event images.
- **Foreign Key Restricts**: Attempting to delete a `Role` while users exist triggers PostgreSQL restriction error code `23503` (foreign_key_violation).
- **Unique Indexes**: Attempting duplicate insertions on `(userId, eventId)` in registrations triggers PostgreSQL unique violation error code `23505`.
